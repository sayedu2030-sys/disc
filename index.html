📱 직원들에게 배포할 때 (필독!)

직원들 스마트폰에는 강사님의 웹앱 주소가 저장되어 있지 않습니다. 반드시 위의 [배포 링크 복사하기]를 눌러 나오는 주소(뒤에 ?sheet=...가 붙은 링크)를 카톡이나 메신저로 공유해야 직원들이 진단 시 구글 시트로 즉시 전송됩니다.

📋 1분 연동 스크립트 복사
  1. 새 구글 스프레드시트를 열고 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭합니다.
  2. 기존 코드를 지우고 위 복사 버튼을 눌러 복사된 스크립트를 붙여넣습니다.
  3. 우측 상단 [배포] → [새 배포] 클릭 후 유형: 웹 앱 선택.
  4. 액세스 권한을 반드시 "모든 사용자(Anyone)"로 설정 후 배포합니다.
  5. 발급된 웹앱 URL을 복사하여 위 입력창에 넣고 [URL 저장 및 활성화]를 누르면 끝납니다!
